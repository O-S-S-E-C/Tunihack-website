## TuniHack 12.0 — Website Components

## 1. Overview

The TuniHack 12.0 website is the official digital platform for Tunisia's national hackathon, organized at ENSI on **November 28–29, 2026**.

The website aims to present the event, showcase its history, promote its program and speakers, highlight partners, and guide visitors toward registration.

The website is divided into three main categories:

- **Homepage sections:** Major sections that structure the visitor experience.
    
- **Reusable UI components:** Elements shared across multiple sections.
    
- **Supporting pages:** Dedicated pages for detailed event information.
    

---

## 2. Homepage Components

## 3. Reusable UI Components

These components can be reused throughout the website.

|Component|Purpose|
|---|---|
|`Button`|Primary and secondary actions|

|`SpeakerCard`|Displays speaker information|
|`SponsorLogo`|Displays partner branding|
|`EventCard`|Displays a talk, workshop, or activity|
|`EditionCard`|Summarizes a previous edition|
|`MemoryGallery`|Displays event photographs|
|`VideoCard`|Displays an aftermovie or recap|
|`CountdownTimer`|Displays time remaining until the event|
|`StatCard`|Presents verified event statistics|
|`FAQAccordion`|Expandable questions and answers|
|`MobileMenu`|Mobile navigation|
|`SocialLinks`|Social media links|

## 5. Previous Editions Structure

Each edition should follow a consistent structure.

**Edition information:**

- Edition number and year
    
- Official theme
    
- Description and objectives
    
- Program highlights
    
- Speakers and partners, when available
    
- Winning projects and achievements
    
- Photo gallery
    
- Official aftermovie or recap video
    

This structure creates a consistent archive while preserving the identity of each edition.

## 7. Component Design Principles

- **Consistency:** Reuse shared components across sections.
    
- **Responsive design:** Support mobile, tablet, and desktop.
    
- **Visual identity:** Follow the official TuniHack 12.0 branding.
    
- **Accessibility:** Ensure readable typography, keyboard navigation, and sufficient contrast.
    
- **Performance:** Optimize images, videos, and animations.
    
- **Maintainability:** Keep sections modular and easy to update.
    
- **Authenticity:** Use real event photographs, verified statistics, and official information wherever possible.
